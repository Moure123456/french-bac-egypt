# french-bac-egypt
An interactive French learning web application designed for the Egyptian Secondary Education Curriculum (Thanaweya Amma - 1Sec, 2Sec, 3Sec). Features curriculum lessons, textbook exercise solutions with AI explanations, grammar, phonetics, audio playback (TTS), audio dialogues, stories, and an integrated AI French tutor.
تطبيق ويب تفاعلي شامل لتعليم اللغة الفرنسية لمنهج الثانوية العامة المصرية (الصف الأول والثاني والثالث الثانوي). يتضمن دروس المنهج، حلول أسئلة الكتاب المدرسي بالشرح التفاعلي، قواعد الجرامر، الصوتيات والنطق، محادثات وقصص ناطقة، ومساعد ذكاء اصطناعي مدمج.
